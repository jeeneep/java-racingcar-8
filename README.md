# 자동차 경주

## 기능 요구 사항

초간단 자동차 경주 게임을 구현한다.

- 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- 각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
- 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.
- 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.
- 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
- 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.
- 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.

### 입출력 요구 사항

입력

- 경주할 자동차 이름(이름은 쉼표(,) 기준으로 구분)
```
pobi,woni,jun
```

- 시도할 횟수
```
5
```

출력

- 차수별 실행 결과
```
pobi : --
woni : ----
jun : ---
```

- 단독 우승자 안내 문구
```
최종 우승자 : pobi
```

- 공동 우승자 안내 문구
```
최종 우승자 : pobi, jun
```

실행 결과 예시
```
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
시도할 횟수는 몇 회인가요?
5

실행 결과
pobi : -
woni : 
jun : -

pobi : --
woni : -
jun : --

pobi : ---
woni : --
jun : ---

pobi : ----
woni : ---
jun : ----

pobi : -----
woni : ----
jun : -----

최종 우승자 : pobi, jun
```

## 프로그래밍 요구 사항 1

- JDK 21 버전에서 실행 가능해야 한다.
- 프로그램 실행의 시작점은 Application의 main()이다.
- build.gradle 파일은 변경할 수 없으며, 제공된 라이브러리 이외의 외부 라이브러리는 사용하지 않는다.
- 프로그램 종료 시 System.exit()를 호출하지 않는다.
- 프로그래밍 요구 사항에서 달리 명시하지 않는 한 파일, 패키지 등의 이름을 바꾸거나 이동하지 않는다.
- 자바 코드 컨벤션을 지키면서 프로그래밍한다.
  - 기본적으로 Java Style Guide를 원칙으로 한다.


## 프로그래밍 요구 사항 2

- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다.
  - 예를 들어 while문 안에 if문이 있으면 들여쓰기는 2이다.
  - 힌트: indent(인덴트, 들여쓰기) depth를 줄이는 좋은 방법은 함수(또는 메서드)를 분리하면 된다.
- 3항 연산자를 쓰지 않는다.
- 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들어라.
- JUnit 5와 AssertJ를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인한다.
  - 테스트 도구 사용법이 익숙하지 않다면 아래 문서를 참고하여 학습한 후 테스트를 구현한다.
    - JUnit 5 User Guide
    - AssertJ User Guide
    - AssertJ Exception Assertions
    - Guide to JUnit 5 Parameterized Tests

## 기능 목록

### 1. `Application` 클래스

- 프로그램 흐름 제어 및 통합 흐름 제어
  - `main()` 메서드를 포함하며 프로그램의 시작점 역할을 한다.
  - `InputView()`, `OutputView()`, `RacingGame()` 객체를 생성하고 연결한다.

### 2. `InputView` 클래스

- 사용자 입력 처리
  - 경주할 자동차 이름 문자열을 입력받아 반환한다.
  - 시도할 횟수 문자열을 입력받아 반환한다.

### 3. `OutputView` 클래스

- 게임 실행 및 최종 결과 출력
  - 실행 결과 메시지("실행 결과")를 출력한다.
  - 라운드별 자동차 진행 상태를 포맷에 맞춰 출력한다.
  - 최종 우승자 안내 문구를 포맷에 맞춰 출력한다.
 
### 4. `Car` 클래스

- 자동차의 상태 및 움직임 로직 관리
  - 이름과 위치(거리) 상태를 가진다.
  - 랜덤 값을 받아 전진 여부를 판단하고 위치를 업데이트하는 `tryMove()` 메서드를 제공한다.
  - 현재 위치를 나타내는 시각화 문자열('-' 개수)을 반환한다.


### 5. `Cars` 클래스

- 복수 자동차 관리 및 게임 로직 수행
  - 자동차 이름 입력값을 받아 `Car` 객체들을 생성하고, 이름 중복 유효성을 검증한다. (잘못된 입력 시 `IllegalArgumentException` 발생)
  - 전체 자동차들의 한 라운드 이동을 지시하는 `raceRound()` 메서드를 제공한다.
  - 가장 많이 전진한 위치를 계산하는 `getMaxPosition()` 메서드를 제공한다.
  - `getMaxPosition()`을 기준으로 최종 우승자 목록을 반환하는 `getWinners()` 메서드를 제공한다.

### 6. `RacingGame` 클래스

- 전체 게임 진행 관리
  - 시도할 횟수와 `Cars` 객체를 가진다.
  - 시도 횟수 입력값의 유효성(양의 정수)을 검증한다. (잘못된 입력 시 `IllegalArgumentException` 발생)
  - 한 라운드의 경주를 진행하고 그 결과를 반환하는 `proceedOneRound()` 메서드를 제공한다.
